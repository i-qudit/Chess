A lightweight, fully functional chess engine built entirely from scratch using Vanilla JavaScript, HTML, and CSS. No external libraries, no frameworks—just pure algorithmic logic and clean code! 🚀

## ✨ Features

* **🧠 Custom Game Engine:** Handles raw move generation, turn validation, and game-state management asynchronously.
* **🛡️ Rule Implementation:** Includes core mechanics like Castling, Check/Checkmate detection, Stalemate, and UI-driven Pawn Promotion.
* **🎨 Responsive UI:** Features a high-contrast, fully responsive CSS Grid board that scales perfectly on both desktop and mobile.
* **⚡ Zero Dependencies:** Built strictly with native web technologies. 

## 🛠️ Tech Stack

* **Logic:** Vanilla JavaScript (ES6+)
* **Styling:** CSS3 (Flexbox & Grid Layouts, Custom Variables)
* **Structure:** HTML5

## ⚙️ Engineering Philosophy 

While this is visually a frontend project, it was developed with a strict **"engine-first"** mindset. Rather than relying on standard external chess libraries, the focus here is heavily on backend-style system logic, data structures, and algorithmic move validation. It is an exploration of matrix manipulation, constraint checking, and state management wrapped in a minimalist, developer-focused interface.
